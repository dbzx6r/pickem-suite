# Contributing

Keep changes focused and describe the user-visible behavior, tests, and migration impact. Contributions to original project material must be offered under the repository’s personal noncommercial license. Only contribute material you have rights to share. Preserve separate third-party licenses; do not relicense upstream code as original project code.

Use synthetic accounts and fixtures. Do not submit real names/emails, credentials, private domains or addresses, database dumps, APNs keys, participant avatars, league screenshots, or private deployment logs. Native server integration belongs here; iOS app source and signing/distribution files do not.

Run the checks in docs/DEVELOPMENT.md. Add regression coverage for changes to authentication, pick locks, ranking, reminders, and migrations. Keep no-stakes validation and third-party-content opt-ins intact. Review a staged diff before committing. Do not use unrelated formatting or dependency churn to hide functional changes.
