# Screenshot provenance

These images were captured from the actual Pickem Suite website on November 12, 2026, using an isolated disposable database. They are screenshots, not design mockups.

- League: **Sunday Social**.
- Eight invented players; all email addresses use the reserved `example.invalid` domain.
- Six completed sample weeks and one simulated in-progress week, with generated picks, results, standings, and achievements.
- Chat messages were written specifically for the demo.
- External sports data and official team logo loading were disabled. Browser requests were restricted to the local demo server.
- No production database, account, chat export, avatar, native app, or private deployment configuration was used.

The desktop views show Midnight, Sunday Field, and Daylight. The mobile browser views show OLED Black. Sample scores, dates, records, and odds do not describe actual games.

To replace these images, use a new disposable database with fictional data and capture the real browser UI.
